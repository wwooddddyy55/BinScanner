Bin Scanner — calibrate detection area

Tap "Refresh snapshot", then click/tap-and-drag on the image to draw a box around where the bin sits. The result below is computed by the add-on's real detection code against this exact snapshot, so what you see here is what a real scan would decide. Adjust the sliders until it matches reality, then copy the values at the bottom into the add-on's Configuration tab in Home Assistant and restart the add-on — this page does not save anything itself.

Color thresholds (HSV, 0-255)
Blob shape filter

Detection only counts the single largest connected red blob in the box (not scattered red pixels), and its bounding-box height/width ratio must fall in this range - rejects thin streaks like glare or a sliver of a passing car.

Infrared (night) detection

When the camera's IR illuminators are on, the image is monochrome and color detection can't work at all - this mode instead compares the box against a per-pixel baseline (mean + spread) built from several stored "bin confirmed absent" reference photos, and looks for the largest blob of pixels that changed more than that pixel's own historical spread. Mode is picked automatically per snapshot based on average color saturation.

Night reference samples
Checking...

Capture one whenever it's dark and you've confirmed the bin is not in frame - ideally on a few different nights (different moon/streetlight/weather conditions), since the baseline is built across all captured samples. The oldest sample is dropped automatically once you're above the max, so re-capturing occasionally also keeps the baseline current as the driveway's appearance drifts (dirt, leaves, seasons).

Confirmation debounce

Require this many consecutive detected scans before notifying, instead of acting on a single frame - guards against a one-off false trigger (headlight sweep, a passing shadow). Only useful if the Home Assistant automation calls /scan more than once per evening; leave at 1 (its default) otherwise, or a single nightly scan will never confirm. A gap longer than the max gap resets the streak so it can't carry over from a previous night.
